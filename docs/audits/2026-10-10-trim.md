# Trim audit of 2026-10-10

This audit finds the code, the tools, the tests, the branches, and the disk use that the app does
not need. The commit of main at the start is `ee1970bd`. The scope is the whole repository: 675
files and about 114,000 lines.

Two read-only agents ran the angles "reuse" and "dead code and altitude". A grep over `src/`,
`tools/`, `e2e/`, and the four HTML entry points checked each claim that a symbol is unused.
`pnpm lint` and `pnpm format:check` pass, so this audit gives no finding that these tools own.

The findings come in the order of their payoff: the cost that the fix removes, divided by the
risk of the fix. A proposal reverses a decision of the user or changes more than 200 lines, so
the user decides it.

## Findings

### 1. Old worktrees and merged branches use 4.8 GB

`.claude/worktrees/` holds 14 worktrees of 2026-10-07 to 2026-10-09, each about 400 MB.

- 43 branches are merged into main.
- The branches `look-l1`, `look-l2`, and `spotlight-pool` are also on main, with other hashes
  (`7900fdd0` and `d8e49899`). `git cherry` shows no other commit.
- Three worktrees have changes that are not committed. Each change is out of date:
  - `contrabass-bow` holds six scratch tests `src/pose/zz-scratch-*.test.ts`.
  - `heads-l3-colors` changes `ears.test.ts`, which main deleted.
  - `bear-judge` changes `src/models/bear/`, which main deleted with the code-built bear.

Fix: remove the 14 worktrees, the 43 merged branches, and the three branches above. Keep the
branches `fox-planes`, `fox-sculpt-shading`, `spike-fox-i3d`, `p4b-elephant-penguin`, and
`look-review-r1`, which stay unmerged by a decision of the user.

### 2. Loose git objects use 143 MB

`git count-objects` gives 7,349 loose objects of 143 MB beside 9 packs of 126 MB.

Fix: run `git gc`. The objects that a branch or the reflog can reach stay.

### 3. Unused symbols

- `SCENE_COLORS.plankLine`, `.stageSide`, and `.podium` (`src/models/colors.ts:45-47`) have no
  reader. `STAGE_COLORS` of `src/models/props.ts:20` replaced them.
- `RiggedRegion` (`src/models/rigged-format.ts:47`) has no reader. `src/models/rigged-body.ts`
  writes `(typeof RIGGED_REGIONS)[number]` two times in its place.
- `REGION_FINISHES` (`src/models/rigged-body.ts:37`) gives `'matte'` to each region.
- `FINISH_ORDER` (`src/models/mesh.ts:48`) repeats the key order of `FINISHES`.
- `src/models/rigged-body.test.ts:16` sets `rigged` on `SPECIES.rabbit`, which has it.

Fix: delete the unused symbols, use `RiggedRegion` in `rigged-body.ts`, and use one finish in
place of the map. About 20 lines.

### 4. Copies of shader formulas with no caller

`hazeDepthFade`, `hazeSurfaceFade`, `hazeDensity`, `coneExit`, and `motePosition`
(`src/scene/beam.ts:158-287`), and `poolFactor` and `spotFactor`
(`src/scene/light-pool.ts:94-116`) copy GLSL into TypeScript. No production code calls them.
Their tests check the copies. A change of a shader can thus drift while the tests stay green.

Fix: delete the copies and their tests. About 80 lines of code.

### 5. Code that only tests read

- `ovalRing()` and `OvalRadii` (`src/models/primitives.ts:563-612`) came in `feb5c8d7`, and no
  commit gave them a caller. Only `primitives.test.ts` calls them.
- `INSTRUMENT_BUDGETS` (`src/models/instruments/catalog.ts:49`), `REFERENCE_STAGE_SIDE`
  (`src/models/layout.ts:72`), `createFrames()` (`src/pose/frames.ts:44`), and `frameBox()`
  (`src/shots/frame.ts:80`) have readers only in tests and test helpers.

Fix: delete `ovalRing()` with its tests, because no part uses it. Move the other four into the
test helpers of their modules. About 70 lines leave the production modules.

### 6. `BodyProportions.torsoDepth` is always 1

No species sets the field since `56cace72`. `src/models/proportions.ts:53,71,93`,
`src/models/trunk.ts:268`, `src/models/fox/fox-body.ts:204`, and `proportions.test.ts` still
carry it.

Fix: remove the field and the factor. Update design 4.4.

### 7. `PlayerPlace.support` copies `cast.support`

Each of the six builders of `src/models/layout-scene.ts` (lines 966, 1000, 1053, 1079, 1192,
1601) sets `support` from `member.cast.support` (`src/models/layout.ts:10`). Each new seat path
must set both.

Fix: remove the field. The four readers (`props.ts:524-527`, `footprint.ts:119`,
`gallery/main.ts:319`, `gallery/sheet-poses.ts:139`) read `place.cast.support`.

### 8. Duplicated test helpers

- `bowed.test.ts:399`, `bow-hold.test.ts:133`, `conductor.test.ts:287`, and
  `pose-at.test.ts:504` repeat `demoSceneOf()` of `test-scene.ts:51`. Six more sites find a
  patched demo by name and throw: `seat-text.test.ts:39`, `view-poses.test.ts:41`,
  `score-speed.test.ts:39`, `solo-light.test.ts:18`, `test-scene.ts:52`, `test-shots.ts:64`.
  About 45 lines.
- `e2e/camera.e2e.ts:7-56` and `e2e/solo-light.e2e.ts:7-71` hold the same `SCENE_ONLY`,
  `FrameOnPage`, `frameOf()`, and `stillFrame()`. About 50 lines.
- `test-body.ts:38,58`, `species.test.ts:73`, `proportions.test.ts:39`, `fox-body.test.ts:24`,
  and `rigged-body.test.ts:19` each build a biped and return its mesh and body. About 80 lines.

Fix: call `demoSceneOf()`, and add one `patchedDemo()` to `tools/patch-demos.ts`. Move the frame
helpers to `e2e/stage-frame.ts`. Add one `builtBody()` to `test-body.ts`.

### 9. Duplicated id lists and type guards

`SPECIES_IDS` is at `tools/build-sculpt.ts:329`, `tools/pack-rigged.ts:651`,
`tools/rig-body.ts:285`, and `tools/glb-init.ts:568`. `species.test.ts:25` and
`player.test.ts:208,237` build the same list. `isSheetId()` is at `tools/sheet-check.ts:530`
and `tools/pose-probe.ts:82`.

Fix: export `SPECIES_IDS` and `isSpeciesId()` from `species.ts`, as `isDemoId()` of
`app/demos.ts:100`. Move `isSheetId()` to `gallery/sheets.ts`.

### 10. Nine smoothstep functions

`pose/rest.ts:30`, `scene/beam.ts:290,312`, `scene/focus.ts:96`, `scene/hall.ts:601`,
`scene/camera.ts:334,387`, `shots/view.ts:180`, and `scene/lights.test.ts:33` each write a

function where its clamp differs.

### 11. Duplicated Blender tool steps

`run()` is at `tools/build-sculpt.ts:314`, `tools/rig-body.ts:271`, and `tools/glb-init.ts:552`.
The Blender command line is at `build-sculpt.ts:367`, `rig-body.ts:310-315`, and

Fix: add `tools/blender-run.ts` with `runBlender()` and `writeModule()`. Proposals 1 and 2 remove

### 12. The skin of a rigged body finds each vertex by its position

`src/models/rigged-body.ts:326-337` builds a `Map` keyed on `"x y z"` strings to find the index
of a vertex. The caller already has the index.

Fix: give the skin of each corner to `MeshBuilder.add()`. `SkinRule`, the string map, and
`blendSkin()` (`src/models/mesh.ts:105`) then go.

### 14. Three clearance helpers split the shells in two ways

`test-clearance.ts:68` splits the shells by a shared edge, and `test-arm-clearance.ts:103` by a
shared corner. The signed distance is at `test-clearance.ts:211` and

### 15. The light of the bear sheet page

`ViewSheet.shadows` and `.light` (`src/gallery/sheets.ts:55-64`), `SHEET_PODIUM`
(`src/gallery/views-main.ts:73`), the `stand` parameter of `buildPodium()`

## Proposals

These proposals reverse a decision of the user or change more than 200 lines.

### P1. Remove the tools of route B

`tools/pack-rigged.ts` (679 lines), its test (151), `tools/rigged-format.ts` (186), and
`tools/spike/fox-gated/` (16 files, 2,661 lines) pack a rigged GLB file into a format that the
app does not read. `pnpm rig-body` now does this work for the app. The test of the tool runs in
each `pnpm test`. The decisions of 2026-10-09 and `2026-10-10-rabbit-glb.md` keep the tools.
The removal also removes the fault in "Possible faults".

### P2. Remove the sculpt tools

`tools/build-sculpt.ts`, `tools/sculpt-rig.ts`, `tools/sculpt-format.ts`, and their tests (1,046
lines), and `tools/blender/build_sculpt.py`, `kit.py`, the shared recipe modules, and the
recipes (3,777 lines in 16 files) build the sculpts of 2026-10-08. The app imports no sculpt.
`rig_body.py`, `inspect_glb.py`, `preview_rig.py`, `rig-body.ts`, and `glb-init.ts` import none
of these files. The decision of 2026-10-09 keeps the tools. With P1, about 8,500 lines go, and
the codec copies of P3 go with them.

### P3. Codec copies, if the tools of P1 and P2 stay

`tools/build-sculpt.ts:88,99,118` and `tools/sculpt-format.ts:9-15,100,124` copy the varint, the
zigzag, and the step helpers of `src/models/packed-mesh.ts:57-265`. Six functions in five files
write or read the same byte streams. About 200 lines. Design 4.4 says that the tools keep their
own copy of the formats, so this fix also edits that design line.

### P4. Remove the audio spike

`src/spike/` and `spike.html` (374 lines) keep alive `demoFromQuery()` (`app/demos.ts:159`),
`Player.renderStats` (`audio/player.ts:180`), the `'stats'` reply, and the render statistics of
the worklet (`processor.ts:31-34,72-91`). The worklet posts one message each second during
play. No tool, e2e test, or CI job opens the page. Design 7 names the page as the audio check of
step 1.

### P5. One type for each kind of body

`SpeciesParams` (`src/models/species.ts:24`) is one flat object for the parametric bodies, the
foxes, and the rigged bodies. The app reads no `ears`, `snout`, `tail`, `size`, `facePattern`,
or `accentParts` of the rabbit and the bear, and no `BEAR_PROPORTIONS`. The `'ears'` accent of
the tan fox does nothing. A union of three kinds removes these fields. The tests then sample a
live parametric species. This change reverses the decision row "The tests take the parametric
rabbit and bear as their samples".

### P6. Old images in the docs

`docs/audits/` holds 27.9 MB and `docs/reviews/` holds 19.4 MB, mostly images. The git history
keeps each file, so a removal makes only the checkout smaller. These folders are records. This
audit does not recommend a removal.

## Possible faults

These faults are out of the scope of a trim.

- `pnpm pack-rigged <glb> rabbit` writes `src/models/rigged/rabbit.ts`
  (`tools/pack-rigged.ts:18,669`), the module that `pnpm rig-body` writes
  (`tools/rig-body.ts:319`), in another format. One run breaks `pnpm typecheck`.
- `tools/pack-rigged.ts:672` and `tools/rig-body.ts:320` do not read the exit status of oxfmt.
- `posedParts()` of `test-clearance.ts` poses each triangle on one bone. The rigged bodies blend
  two bones, so a clearance test of the bear measures a mesh that differs from the drawn mesh.

## Unverified

- Two vertices at one position with different weights get the weights of the last vertex
  (`src/models/rigged-body.ts:326-337`). To reproduce, pack a body with a seam of two vertices
  at one position and different weights, then compare the posed corners with the weights of the
  packed mesh.

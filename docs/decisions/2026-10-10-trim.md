# Decisions of the trim audit

The Section column names a section of the design. [`design.md`](../design.md) gives the file of
each section.

On 2026-10-10, the user approved the trim audit
[`2026-10-10-trim.md`](../audits/2026-10-10-trim.md). A row that starts with "The user" gives a
decision of the user. The agent of the tools trim decided the other rows. The user can reverse
each decision. Then update the section that holds it, and remove its row.

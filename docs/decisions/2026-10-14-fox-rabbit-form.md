# Decisions of the form of the red fox and the rabbit

The Section column names a section of the design. [`design.md`](../design.md) gives the file of
each section.

On 2026-10-14, the user looked at the rabbits and the red foxes in the rest pose and said: "make
the head of the fox larger so that it appears cuter", "make the legs of the fox and rabbits
longer, and the seat higher.", "fix the size of the violin on the fox and rabbit.", and "optimize
the default rest pose of the rabbit and fox so that they're more natural." The manager of the
session and the agent of the branch `fox-rabbit-form` decided the other rows. The report
[`2026-10-14-fox-rabbit-form.md`](../research/2026-10-14-fox-rabbit-form.md) gives the measures,
the sources, and the images. The user can reverse each decision. Then update the section that
holds it, and remove its row.

# Decisions of the retro of the mouse and elephant mesh rounds

The Section column names a section of the design. [`design.md`](../design.md) gives the file of
each section.

On 2026-10-19, after the merge of the mouse mesh (`2026-10-19-mesh-mouse.md`) and of the elephant
mesh (`2026-10-19-mesh-elephant.md`), the manager asked each agent what would make the next round
faster (user rule of 2026-10-12, `docs/briefs/studio-body.md`, section 6). The two agents gave 10
items. The user slept and asked for no questions, so the manager chose. The first rows give the
choices of the manager. The agent of the tool round adds its rows after them. The report
[`2026-10-19-mesh-retro.md`](../research/2026-10-19-mesh-retro.md) gives the times and the
measures. The user can reverse each decision. Then update its section, and remove its row.

| Decision | Section |
|---|---|
| A saved tool gives a ready `raise` rule of a corrective shape from the folded faces of a role, in place of probes that each round copied by hand. Both agents asked for it (about 40 minutes for each round). `pnpm fold-probe --faces` also gives the middle of each face in the units of the source, for `weights.rigid`. | 9.8 |
| `pnpm pose-depth` gets a fast mode that measures only the samples at the note targets, and `pnpm hold-fit` gives the target errors. The elephant round ran the 5-minute sweep 5 times to read the reach of the mallets. | 9.8 |
| `pnpm hold-fit` gives the turn of each upper arm from its bind direction and of each paw from its forearm, because the mouse round saw twisted upper arms only in the close views. | 9.8 |
| `--set` of the hold tools takes a text value for a text field, such as the hands rule of the timpani. | 9.8 |
| `pnpm rig-mesh --check` takes hold changes in memory for its fold probe, so that a round fits a corrective shape to a hold with no commit. | 9.8 |
| The export takes the tip of the nose only near the middle plane, and the checks warn when the nose tip or the mouth is off the middle plane. A whisker tip of the mouse moved the oboe 0.33 m. | 4.4 |
| `pnpm hold-reach` and `pnpm mesh-options` take the percussion instruments, because the badger mesh plays percussion. This item comes last in the tool round. | 9.8 |
| The tool round also cuts `docs/agents/model-traps.md` to its limit of about 3,000 words. | 9.8 |
| The manager wrote three rules directly: a sweep keeps its modules unchanged while it runs (`docs/agents/workflow.md`), the brief gives the pixel heights of the species and of an anchor, and the first hold fit compares 3 or 4 elbow directions (`docs/briefs/studio-body.md`, section 7). | 9.8 |
| A floor option of `studio.tailBind` waits for the monkey mesh. Only the mouse has a long tail on the floor, and the item saved about 15 minutes. | 4.4 |
| `pnpm raise-fit` proposes the fade of the four arm rules: full to 10° (or to the angle of 90% of the folded samples), none 10° later. An arm rule gets no `turns.hand` (`tools/raise-fit.ts`). | 9.8 |
| `pnpm fold-probe --faces` takes the source middles from a rig run of 2 s, so each module keeps its bytes (`face_sources()` of `tools/blender/rig_mesh.py`). | 9.8 |

| No demo has a snare drum or a xylophone, so the strike tools measure none (`tools/strike-reach.ts`). | 9.8 |

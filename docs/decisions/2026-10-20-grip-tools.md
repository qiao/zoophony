# Decisions of the retro of round elephant-grip

The Section column names a section of the design. [`design.md`](../design.md) gives the file of
each section.

The agent of round `elephant-grip` spent most of 95 minutes on waits. The manager gave the tool
round `grip-tools` with four items. The user slept, so the agent made each choice below. The user
can reverse each decision. Then update its section, and remove its row.

| Decision | Section |
|---|---|
| With no `--demo`, a role that no demo of `FIT_DEMOS` has takes its one demo with the most notes of the role, and not all its demos (`roleNotes()`, `chooseDemos()` of `tools/hold-fit.ts`). The conductor counts the beats. `pnpm hold-fit timpanist` took 4:22 on four demos and 1:47 on `brahms-2`. | 9.8 |
| `pnpm hold-fit --base` with no `--demo` gives that one demo to both children by name, because the hold-fit of an older commit takes all demos of such a role. | 9.8 |
| The brief template said "never on one demo" for a fit (`docs/briefs/studio-body.md`, section 7). The brief of this round asks for one default demo, so a round fits each step on the default demos, and checks the last fit with `--demo all`. | 9.8 |
| `pnpm arm-check <role> --explain stretch\|flat` gives each value from the rest and from the bind, `MOVES` where the rest adds stretch, and the worst edges or rings with their bones (`explainLines()`). The timpanist: L lift 0.220 from the rest, 0.178 from the bind (`a116a9e8`: 0.090, 0.199). | 9.8 |
| The failure of `hold-fit --base a116a9e8` in round `elephant-grip` came from the working tree: its mesh had 4 open loops, and `ELEPHANT_BODY_LOOPS` was still 5. The tool ended the base child and reported the base, with no cause. Now `probeBeside()` names the child that failed first, with its error output (`probeBoth()`). | 9.3 |
| `pnpm close-views play` takes more than one `--set`. One build holds each variant, the page applies the variant of its query `holds`, and each variant renders into `set-<n>/` (`variantPlugin()`, `playParts()`). Two variants at the elephant took 22.0 s, and one variant 12.5 s. One `--set` keeps its build and its folder. | 9.8 |

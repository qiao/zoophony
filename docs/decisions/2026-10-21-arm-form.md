# Decisions of the arm form of the rabbit and the pig

The Section column names a section of the design. [`design.md`](../design.md) gives the file of
each section.

On 2026-10-21, the user said: "the rabbit and pig's arms are still very deformed. take screenshot
for youself. note that the fox's arm is looking great." Phase 1 measured the causes and showed
variants, and the user chose one for each animal. The reports
[`2026-10-21-arm-form.md`](../research/2026-10-21-arm-form.md) and
[`2026-10-21-rabbit-right-arm.md`](../research/2026-10-21-rabbit-right-arm.md) give the measures.
The user can reverse each decision. Then update its section, and remove its row.

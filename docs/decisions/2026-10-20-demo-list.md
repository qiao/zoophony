# Decisions of the demo list

The Section column names a section of the design. [`design.md`](../design.md) gives the file of
each section.

On 2026-10-20, the user said: "remove the cover image from the demo list", and "make sure
there's no layout shift in the track list when a track is playing". The user then asked if tabs
should separate the tracks, the mute and solo, and the settings and credits. The agent advised
three tabs, and the user said: "move credit to settings and proceed to impl". Then the user asked: "instead os saying “demos” should we say something like “tracks” or other more accurate and common terms". Last, the user said: "do not support clicking on animals to highlight it in seats tab". The user can
reverse each decision. Then update its section, and remove its row.

| Decision | Section |
|---|---|
| The user, first quote above: a row of the demo list shows no cover. `ui/covers.ts` is removed. | 2.8 |
| The user, second quote above: each row of the demo list keeps a column of 34 px for the level meter, so that the text does not move when the meter comes into the row. | 2.8 |
| The user, third quote above: the drawer has the tabs "Pieces", "Seats", and "Settings" in place of three sections with headings. The link "Credits" moves from the footer to the end of "Settings". | 2.3, 2.8 |
| The file button moves below the demo list, because it also selects a piece. The seat list loses its collapse button, because its tab hides it. | 2.8 |
| A wide window opens the drawer at start at the tab "Pieces", in place of the expanded seat list of the mockup. | 2.3, 2.8 |
| The tabs stick to the top of the drawer. The arrow keys, Home, and End move between the tabs and do not seek (`focusKindOf()` gives `menu` for a tab). | 2.4, 2.8 |
| The user, fourth quote above: the tab and the list are "Pieces". "Track" names a track of a MIDI file in this app, and the first screen already says "Select a piece". The code keeps the name "demo". | 2.3, 2.8 |
| The user, fifth quote above: a click on an animal does nothing. The pick of the scene (`scene/pick.ts`), `Drawer.openFromStage()`, and the marked row of the seat list are removed. The open drawer always moves the stage. The source line of a seat is for a screen reader only. | 2.3, 2.8 |

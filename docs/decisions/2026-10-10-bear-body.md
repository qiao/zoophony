# Decisions of the bear body

The Section column names a section of the design. [`design.md`](../design.md) gives the file of
each section.

On 2026-10-10, the user set the goal: "make the bear conductor look like this reference image",
with the image `docs/reference/bear-views.png`. During the work, the user added: "make sure that
the conductor just use one baton". The agent of the bear body decided the other rows. The report
[`2026-10-10-bear-body.md`](../research/2026-10-10-bear-body.md) gives the measures and the
images. The user can reverse each decision. Then update the section that holds it, and remove its
row.

Later on 2026-10-10, the bear took the rigged body of the GLB file of the user
([`2026-10-10-bear-glb.md`](2026-10-10-bear-glb.md)). The rows of the code-built body went then.
The rows of the conductor, the podium, the baton, the colors, and the sheet page stay.

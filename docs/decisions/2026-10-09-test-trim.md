# Decisions of the test trim

The Section column names a section of the design. [`design.md`](../design.md) gives the file of
each section.

On 2026-10-09, the user approved three changes that make the wall time of `pnpm test` shorter.
Each behavior check stays. First, remove the code that has no user, and its tests: the meerkat
species, which has had no seat since 2026-10-06, and the tip help of a short bow arm, which no
body needs after the body revert of 2026-10-09. Second, sample the three slow sweeps less often.
Third, split the three slow test files into smaller files, because Vitest runs the tests of one
file in one worker. The agent of the test trim decided the details in the rows below. The user
can reverse each decision. Then update the section that holds it, and remove its row.

| Decision | Section |
|---|---|
| The meerkat leaves `SpeciesId`, `SPECIES`, the colors, and the seat text. Its ear, snout, tail, and face pattern types stay, because other species use them: the hippo has `small` ears, the mouse the `pointed` snout, and the panda the `eye-patches`. The test of the hand tools builds the badger, the percussion player, in place of the meerkat. The test of `limitReach()` builds the polar bear, the pianist | 4.3, 4.5 |
| The `girth` of `SpeciesParams` goes with the meerkat, the only species with a value other than 1.0. The width of the torso and the thickness of the limbs are now the same for all species, in `H`. Each player model stays the same to the bit (the same SHA-256 of the meshes, the skeletons, and the body points of each species with each instrument). The rows of older files that give the bear and the polar bear the girth 1.0 still hold: that is the one width of all species | 4.3, 4.4, 4.5 |
| The tip help of a short bow arm leaves `pose/bowed.ts` and `pose/bowed-rig.ts`, with its test. Before the removal, a print of `bowedRig()` gave the tip help 0 for each bowed player of each demo at each section size, of the four chamber test files, and of the three bowed sheets of the views page. Only made-up players had a tip help, such as a rabbit with a cello, or the dog with its cello on a high stool. The search of the bow range now poses the shoulder one time, because the shoulder turn no longer changes with the place of the bow. `hairShare()` goes too, because only the tip help used it. This row replaces the tip help row of `2026-10-08-fox-arms.md` and the row of `2026-10-09-body-revert.md` that kept the tip help | 5.3 |

# Decisions of the low seats

The Section column names a section of the design. [`design.md`](../design.md) gives the file of
each section.

On 2026-10-11, after the short legs, the seated rabbits, foxes, and wolves still looked almost the
same in the default views. The manager offered to "lower all chairs from 0.92 to about 0.75 head
heights, so that the seated legs are clearly shorter; it lowers the sheet match a little", and the
user said "do it". The agent of the low seats decided the other rows. The report
[`2026-10-11-low-seats.md`](../research/2026-10-11-low-seats.md) gives the measures, the sheet
checks, and the before and after images. The user can reverse each decision. Then update the
section that holds it, and remove its row.

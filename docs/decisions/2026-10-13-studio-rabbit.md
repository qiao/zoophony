# Decisions of the studio rabbit in the app

The Section column names a section of the design. [`design.md`](../design.md) gives the file of
each section.

On 2026-10-13, the user gave a new sheet of a low-poly rabbit and decided: "create a low-poly model
for the rabbit following this reference image and replace the main-app's rabbit by this new one".
The manager of the session and the agent of the branch `rabbit-app` decided the other rows. The
report [`2026-10-13-studio-rabbit.md`](../research/2026-10-13-studio-rabbit.md) gives the measures
and the images. Later on 2026-10-13, the user replaced the studio rabbit by a mesh of the user
([`2026-10-13-mesh-rabbit.md`](2026-10-13-mesh-rabbit.md)). The rows here hold for that body too,
unless that file replaces them. The user can reverse each decision. Then update the section that
holds it, and remove its row.

# Decisions of the short legs

The Section column names a section of the design. [`design.md`](../design.md) gives the file of
each section.

On 2026-10-11, the user said: "make these animals look more like the reference images.
specifically right now their legs too long." The agent of the short legs decided the other rows.
The report [`2026-10-11-short-legs.md`](../research/2026-10-11-short-legs.md) gives the measures,
the sheet checks, and the images. The user can reverse each decision. Then update the section
that holds it, and remove its row.

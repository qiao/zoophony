# Decisions of the FLAC hall

The Section column names a section of the design. [`design.md`](../design.md) gives the file of
each section.

The round `perf-hall` of 2026-10-21 gave the hall reverb a FLAC file. The manager decided on the
question 3 of the round `perf-load`: "yes, give the hall reverb a lossless FLAC file, with a
fallback to the WAV file". The addendum
[`hall-flac.md`](../research/2026-10-21-load-performance/hall-flac.md) gives the measures. The user
can reverse each decision. Then update its section, and remove its row.

| Decision | Section |
|---|---|
| The manager: "yes, give the hall reverb a lossless FLAC file, with a fallback to the WAV file". The `Player` fetches the FLAC file, and the WAV file only when `decodeAudioData()` refuses it (`#loadHall()` of `audio/player.ts`). | 6.8 |
| `tools/hall-flac.py` writes the FLAC file one time with libsndfile through `uv`, and the repository keeps the file beside the WAV file. The build has no encoder. | 6.2, 7.3 |

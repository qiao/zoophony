# Decisions of the head size and the face of the wolf

The Section column names a section of the design. [`design.md`](../design.md) gives the file of
each section.

On 2026-10-20, the user said: "make the wolf's head the same size as the fox. reduce its body if
needed", and "the wolf look sad now. make it look happier". The report
[`2026-10-20-wolf-face.md`](../research/2026-10-20-wolf-face.md) gives the measures. The user can
reverse each decision. Then update its section, and remove its row.

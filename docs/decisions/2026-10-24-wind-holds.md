# Decisions of the wind holds of the wolf, the mouse, and the tan fox

The Section column names a section of the design. [`design.md`](../design.md) gives the file of
each section.

On 2026-10-24, the user said: "fix how the wolf, tan fox, and mouse are holding the instrument, in
both rest and play modes. validate through screenshots". The main session decided the rows below
with no questions. The report [`2026-10-24-wind-holds.md`](../research/2026-10-24-wind-holds.md)
gives the measures and the images. The user can reverse each decision. Then update its section,
and remove its row.

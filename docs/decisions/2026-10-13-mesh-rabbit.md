# Decisions of the rabbit mesh of the user

The Section column names a section of the design. [`design.md`](../design.md) gives the file of
each section.

On 2026-10-13, the user gave the mesh `assets/models/rabbit/rabbit-4.glb` and said: "replace the
rabbit by using the model at @~/Downloads/rabbit-4.glb. Note that you need to rig it yourself." The
manager of the session and the agents of the branch `rabbit-mesh` (the rig round, the app round, and
the round of the folds and the round after the review of 2026-10-14) decided the other rows. The
report [`2026-10-13-rabbit-mesh.md`](../research/2026-10-13-rabbit-mesh.md) gives the measures and
the images. The user can reverse each decision. Then update the section that holds it, and remove
its row.

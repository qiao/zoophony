# Decisions of the bear eye size

The Section column names a section of the design. [`design.md`](../design.md) gives the file of
each section.

On 2026-10-23, the user said: "make the eyes of bear and polar bear slightly larger". The main
session decided the rows below from a lineup of the head views at about 1.1, 1.15, and 1.25 times
the old size of each bear. The 2x crops of the front and of the front at 60° are in
[`2026-10-23-bear-eye-size/`](../research/2026-10-23-bear-eye-size/), the old size at the left. The
user can reverse each decision. Then update its section, and remove its row.

| Decision | Section |
|---|---|
| Bear: the eyes take 1.15 of the pea eye size (1 before). At 1.25, the eyes cover the edge of the muzzle. With the T-pose mesh, the user said: "make the bear's eye 0.7x the size", so the bear takes 0.805 (`bear-eyes-tpose.webp`, 1.15 in the top row). | 4.4 |
| Polar bear: the eyes take 0.85 of the pea eye size (0.7 before). They fill the painted lids. At 0.9, they come near the size 1 that the user called too big. This row replaces the polar bear row of `2026-10-23-night-fixes.md`. | 4.4 |

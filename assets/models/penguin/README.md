# Penguin model

This folder holds the penguin mesh that the user gave. The app does not serve it.

## penguin.glb

`penguin.glb` is a mesh with no skeleton. The user gave it on 2026-10-21. The file is the file of
the user, byte for byte. The rig of this project makes a studio body from it, as for the other
meshes of the user (route 3 of `AGENTS.md`, `tools/mesh-rigs/penguin.json`): `pnpm rig-mesh
penguin` writes the rigged file `penguin.rig.glb`, and `pnpm studio-body penguin` writes the
module `src/models/studio/penguin.ts` from it. The app does not serve the two GLB files.

On 2026-10-21, the user said: "use the following models: 1. deer: ...deer...glb 2. rhino:
...rhino...glb 3. penguine: ...penguin...glb. make the deer sit on the chair. make sure its hip is
fully sit on the chair. make the rhino and penguine stand. make sure the size of these models are
similar to that of the previous parametric model".

## penguin-beak.glb

`penguin-beak.glb` is a copy of `penguin.glb` with the beak split, so that the beak opens
(user, 2026-10-21: "make the penguins able to open the beak"). `source` of
`tools/mesh-rigs/penguin.json` names it, and `penguin.glb` does not change. The script
`docs/research/2026-10-21-penguin-beak/beak_split.py` makes it in a headless Blender, and gives
the same file again:

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup \
  --python docs/research/2026-10-21-penguin-beak/beak_split.py -- \
  assets/models/penguin/penguin.glb assets/models/penguin/penguin-beak.glb 0.883
```

The edits, in the units of the studio (`beak-split.log` of the research folder):

1. The vertices are welded at 1e-5 units of the file, as `pnpm rig-mesh` welds them.
2. The level plane at y 0.883, the height of the tip of the beak, cuts the 93 faces of the beak.
   The cut is a path of 20 edges from the left corner of the mouth (x 0.045, z 0.140) around the
   tip to the right corner (x -0.045).
3. The faces split along the path into an upper part and a lower part. Each corner of the mouth
   stays one vertex.
4. The vertices of the path move 0.0005 units of the file up on the upper part and down on the
   lower part, so that the weld does not join them again. The outer form of the closed beak does
   not change otherwise.
5. A cap of 21 corners closes each part. The two caps share the edge between the corners of the
   mouth, and their normals point into the mouth.
6. A patch of 24 × 24 pixels of the mouth color `#4d2312` goes into a free place of the base color
   texture (u 0.044, v 0.009), and the caps take its UV.

The edited mesh has 3,185 triangles, against 3,103 for `penguin.glb`, and the same 2 open edges
and 3 edges with more than two faces.

## penguin-edge.glb

`penguin-edge.glb` is a copy of `penguin-beak.glb` with the faces cut along the black and white
edge of the texture, so that each face of the rig lies on one side and the edge runs through the
faces as on the mesh of the user (user, 2026-10-28: "the penguine's head has unnatural gradient
between black and white. Make it look more like the original mesh", then the choice to cut the
faces along the edge). `source` of `tools/mesh-rigs/penguin.json` names it, and the files before
it do not change. The script `docs/research/2026-10-28-penguin-edge/edge_cut.py` makes it in a
headless Blender, and gives the same file again:

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup \
  --python docs/research/2026-10-28-penguin-edge/edge_cut.py -- \
  assets/models/penguin/penguin-beak.glb assets/models/penguin/penguin-edge.glb
```

The edits (`edge-cut.log` of the research folder):

1. The vertices are welded at 1e-5 units of the file, as `pnpm rig-mesh` welds them.
2. Each vertex is light or dark by the Oklab lightness 0.5 of the texture at its UV. A vertex on
   the orange beak or feet has no side, because a cut at the root of the beak gave thin faces that
   folded when the beak opened.
3. Each of the 182 edges between a light and a dark vertex splits where the texture changes along
   it, from 0.15 to 0.85 of the edge, and each of the 178 faces with two new vertices splits along
   the line between them.

The edited mesh has 3,549 triangles, against 3,185 for `penguin-beak.glb`, and the same 2 open
edges and 3 edges with more than two faces.

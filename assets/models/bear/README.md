the user, byte for byte. The rig of this project makes the studio body of the bear conductor from
it (route 3 of `AGENTS.md`, `tools/mesh-rigs/bear.json`): `pnpm rig-mesh bear` writes the rigged
file `bear-mesh.rig.glb`, and `pnpm studio-body bear` writes the module `src/models/studio/bear.ts`
from it.

## rhino.glb

`rhino.glb` is a mesh with no skeleton. The user gave it on 2026-10-21. The file is the file of
the user, byte for byte. The rig of this project makes a studio body from it, as for the other
meshes of the user (route 3 of `AGENTS.md`, `tools/mesh-rigs/rhino.json`): `pnpm rig-mesh rhino`
writes the rigged file `rhino.rig.glb`, and `pnpm studio-body rhino` writes the module
`src/models/studio/rhino.ts` from it. The app does not serve the two GLB files.

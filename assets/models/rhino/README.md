# Rhino model

This folder holds the rhino meshes that the user gave, and copies of them. The app does not serve
them. The rig uses `rhino-apose-arms.glb`, a copy of `rhino-apose.glb` with rebuilt arms, since
2026-10-27. The other files stay as the record of the earlier rounds.

## rhino-apose.glb

`rhino-apose.glb` is a mesh with no skeleton, with the arms in an A-pose: about 45° down and apart
from the trunk below the shoulders. The user gave it on 2026-10-23 and said: "replace the model for

`pnpm rig-mesh rhino` rigs it with no cut and no split of its faces (`tools/mesh-rigs/rhino.json`).

## rhino-apose-arms.glb

`rhino-apose-arms.glb` is a copy of `rhino-apose.glb` with new arms, made on 2026-10-27. The rig
config reads it, with the weights `rhino-apose-weights.json` of the same Blender session. The file
of the user stays byte for byte.

On 2026-10-26, the user said: "the rhino's arms are stretched / twisted in unnatural ways". The long
thin faces of each forearm and the two bones of the forearm twisted the skin into a thin band. The
user allowed loop edges, retopology, and extra bones for the arm and wrist twist on 2026-10-24.
The copy replaces the faces of each arm from 0.4 of the upper arm to 0.3 of the paw with a quad
tube of 13 rings of 16 vertices, wrapped onto the source arm and bridged to the trunk and to the
paw. The arm faces take the fur color of the source arm (a bake into a strip of the atlas) and the
normals of the source surface. The inner lower side of each upper arm and its shoulder loop move
0.015 units toward the arm axis, so that the thick upper arm stays out of the round belly when the
elbow points down. The faces of the paws, the trunk, the legs, and the head are the faces of the
user (`docs/decisions/2026-10-26-fifth-review-rhino.md`).

## rhino.glb

`rhino.glb` is the first mesh with no skeleton, with the arms down beside the belly. The user gave
it on 2026-10-21. The rig used it and its copies until 2026-10-23. The file is the file of
the user, byte for byte. The rig of this project makes a studio body from it, as for the other
meshes of the user (route 3 of `AGENTS.md`, `tools/mesh-rigs/rhino.json`): `pnpm rig-mesh rhino`
writes the rigged file `rhino.rig.glb`, and `pnpm studio-body rhino` writes the module
`src/models/studio/rhino.ts` from it. The app does not serve the two GLB files.

On 2026-10-21, the user said: "use the following models: 1. deer: ...deer...glb 2. rhino:
...rhino...glb 3. penguine: ...penguin...glb. make the deer sit on the chair. make sure its hip is
fully sit on the chair. make the rhino and penguine stand. make sure the size of these models are
similar to that of the previous parametric model".

## rhino-arms.glb

`rhino-arms.glb` is a copy of `rhino.glb` with one local edit, made on 2026-10-22. No rig reads
it since the revert `fee18ae8`: the user found the left arm of its rig "completely deformed". The
rig reads `rhino-tubes.glb` (below).

On 2026-10-22, the user said: "the panda and rhino's arms also got deformed". Each thick arm joins
the trunk from the paw up to the shoulder, so the cut of the rig closed the inner side of each arm
with one flat cap. The cap showed as a flat dark sheet when the forearm turned to the tuba. The
copy removes the 48 (left) and 49 (right) faces that join each arm to the trunk below the cut
height, and closes each arm with a round patch of 20 and 19 new vertices. The hole of the trunk
stays open, and the cut of the rig closes it (`docs/research/2026-10-22-rhino-arm.md`).

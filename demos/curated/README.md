# Curated Orchestral MIDI Library

This directory contains vetted, high-quality orchestral and symphonic MIDI files that match
Zoophony's musical criteria: positive, joyful, and cheerful classical compositions suitable for
the WebGL 3D animal orchestra.

All files are either:
1. Exported from **OpenScore Orchestra** (IMSLP scores, CC0 1.0) using Zoophony's MuseScore 4
   pipeline in `tools/musescore/` with annotations removed and proper General MIDI program
   mappings.
2. Directly derived from **Mutopia Project** scores with explicit **Public Domain** dedications
   by the typesetters.

None of these files use CC BY-SA (per design section 8.1).
